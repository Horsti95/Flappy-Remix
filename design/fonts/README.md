# Font licenses

Park the EULA / readme / preview files for every font we self-host here
(the binaries live in `public/fonts/`). For Embolism Spark, that's:
`1001fonts-embolism-spark-eula.txt`, `README.txt`,
`PRIVIEW-Embolism-Spark.png`.

Before shipping a font commercially, re-read its EULA — 1001fonts
licenses vary per font (some are personal-use only).
