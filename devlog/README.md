# Glide — Devlog

A running log of building **Glide** (a Flappy-style game) as a **vibe-coding
project**: built conversationally with an AI pair, shipped in small PRs, each
verified (typecheck + build + tests) before merge.

Posts are newest-first. Cadence: every ~1–3 days, summarizing what changed.
Each post maps to merged PRs so it's honest about what actually shipped.
